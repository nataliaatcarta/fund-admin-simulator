# Fonts

No font files are committed. Download these yourself (both open-licence, SIL OFL, via Google Fonts) and drop the files in this folder:

| Role | Font | Link |
|---|---|---|
| Display (titles, startup names, quarter banners) | **Pixelify Sans** | https://fonts.google.com/specimen/Pixelify+Sans |
| Body UI text (emails, dialogue, glossary, tooltips) | **Atkinson Hyperlegible** | https://fonts.google.com/specimen/Atkinson+Hyperlegible |

Both are the fonts used by the sketchbook style guide. Pixelify Sans stays crisp at multiples of its design size; Atkinson Hyperlegible keeps long dialogue readable at small sizes (accessibility setting: "text size").

The hand-made 5x7 pixel font used by the logo is in `assets/art/ui/branding/pixel-font-atlas.png` (+ `.json` glyph rects). It is uppercase only and intended for tiny labels, the logo and startup-name plates; not for body text.
